Bilder-Ordner
=============

Hier die Bilddateien ablegen. Fehlen sie, blendet die Website die <img>-Tags
automatisch aus (onerror), sodass nichts „kaputt“ aussieht.

Benötigt / referenziert:
- logo.png         Logo im Header (transparenter Hintergrund, Höhe ~80px)
- logo_footer.png  Logo im Footer (helle Variante für dunklen Hintergrund)
- team.jpg         Team-/Inhaberfoto (Abschnitt „Über uns“)
- karriere.jpg     Foto für den Karriere-Abschnitt
- favicon          aktuell wird logo.png als Favicon genutzt

Optional / empfohlen:
- Vorher-Nachher-Fotos realer Projekte (Referenzen)
- Detailaufnahmen von Fassaden, Innenräumen, Lackierungen

Empfohlene Formate: PNG für Logos, JPG/WebP für Fotos. Fotos vor dem Upload
komprimieren (z. B. < 300 KB) für schnelle Ladezeiten.
